# Python Banking Balance Simulator

A simple command-line banking simulator developed using Python. This project allows users to manage a simulated bank account through a menu-driven interface.

## Features

- **Check Balance:** Display the current account balance.
- **Deposit:** Add money to the account.
- **Withdraw:** Withdraw money while checking available funds.
- **Input Validation:** Reject invalid, non-numeric, zero, and negative transaction amounts.
- **Exception Handling:** Handle invalid numeric conversions using `try` and `except`.
- **Interactive Menu:** Keep the application running until the user chooses to exit.

## Technologies Used

- Python 3
- Built-in Python functions and libraries

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/python-banking-balance-simulator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-banking-balance-simulator
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## Initial Account Balance

The simulator starts with an initial balance of **$1,000.00**.

All transactions are simulated locally. No real banking operations or financial transactions take place.
